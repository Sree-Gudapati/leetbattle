# Show password

## Description
Serves US-5 (UI/UX). Every password field has an eye button that shows or hides what was typed, so a player can check their password before sending it. Issue #85.

## Specs
- A password field hides its text until the player clicks the eye button, and hides it again on a second click.
- The button is on the sign-in page, the sign-up page, the reset page and both password fields in Settings.
- Each field is shown or hidden on its own.
- The button's screen reader label is "Show password" while the text is hidden and "Hide password" while it is shown, and it reports whether it is pressed.
- Fields that are not passwords have no eye button.

## Requirements
- The button is part of `AuthField` in `frontend/app/login/components/components.tsx`, so every password field gets it.
- Use only the theme classes defined in docs/frontend/theming.md. No new dependencies.
- Frontend tests (`frontend/test/password.test.tsx`) mock the signed-in user and do not touch backend services.

## Acceptance criteria
1. The password field on the sign-in page hides its text by default.
2. Clicking "Show password" shows the text, and the button becomes "Hide password".
3. Clicking "Hide password" hides the text again.
4. The button reports that it is pressed while the password is shown.
5. The sign-up page has the button.
6. Both password fields in Settings have the button, and showing one does not show the other.
7. The Email field has no eye button.
